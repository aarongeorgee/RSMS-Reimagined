# Implemented futuristic upgrades

- Live Today Engine: current-period progress, minutes remaining, next-class countdown and live state labels.
- PWA/offline: install prompt, app shell caching, offline indicator, cached academic reads and queued attendance/timetable mutations that replay when connectivity returns.
- What-If attendance: tap future subject periods in Forecast to simulate exact absences without changing real attendance.
- Smart notifications: attendance threshold alerts, academic events and next-class reminders are generated from application state.
- Theme system: Light, Dark and System modes with persisted preference and device-theme following.
